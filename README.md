# تطبيق المكتبة الشاملة في الرياضيات (Math Comprehensive Library)

تطبيق متقدم للهواتف الذكية بنظام أندرويد (Android) مصمم بأحدث تقنيات **Jetpack Compose** و **Material Design 3** بالنمط الفضائي النيوني الداكن (Dark Sci-Fi Theme)، يدمج بين محاكاة المجسمات ثلاثية الأبعاد التفاعلية، حل وتوضيح النظريات والقوانين الرياضية المعقدة، والتقييم الحسابي المباشر عبر محرك **mXparser**.

## مميزات التطبيق الرئيسية

1. **الواجهة الرئيسية التفاعلية ثلاثية الأبعاد (3D Simulation Dashboard):**
   - منصة محاكاة رسومية ثلاثية الأبعاد تفاعلية تتيح تدوير وفحص المجسمات الهندسية (المخروط الفراغي، الكرة ثلاثية الأبعاد، محاور الإحداثيات $X, Y, Z$) عبر اللمس والإيماءات المباشرة.
   - موجات هارمونية نيونية متحركة ومؤشرات إحصائية بصرية حية.
   - شريط سريع لاختيار وتبديل المعادلات والنظريات الشهيرة (مثل تكامل غاوس، متطابقة أويلر، حجوم المجسمات، والقانون العام للمعادلة التربيعية).

2. **الحفظ والتصدير إلى الهاتف (Save to Phone):**
   - زر دائري بارز مع توهج نيوني نابض يتيح تصدير وحفظ نتائج المحاكاة والقوانين مباشرة إلى ذاكرة الجهاز الداخلية بصيغة نصية موثقة بالتاريخ والوقت.
   - إمكانية نسخ القوانين الرياضية فورياً إلى الحافظة ومشاركتها مع مختلف التطبيقات.

3. **شاشة نظرة عامة على القوانين والنظريات (Math Overview):**
   - مكتبة تصنيفية مفصلة تشمل:
     - **الجبر والمعادلات** (المعادلة التربيعية، متطابقات الجبر).
     - **التفاضل والتكامل** (تكامل غاوس، مشتقات الدوال).
     - **الهندسة الفراغية** (حجوم ومساحات الكرة، المخروط، والأسطوانة).
     - **الإحصاء والاحتمالات** (الانحراف المعياري، التوزيع الطبيعي).
     - **الثوابت والمتطابقات الشهيرة** (متطابقة أويلر، النسبة الذهبية $\phi$).
   - حاسبة تفاعلية مدمجة داخل كل بطاقة قانون تتيح إدخال المتغيرات والحصول على الحل الفوري.

4. **محرك البحث الرياضي والحاسبة العلمية المباشرة (Math Search & Calculator):**
   - محرك بحث سريع ودقيق يبحث في العناوين والصيغ وشروحات النظريات.
   - حاسبة تعبيرات علمية تدعم الدوال المثلثية، الأسية، الجذور، والثوابت الرياضية عبر مكتبة `mXparser`.
   - شريط اختصارات علوي لإدراج الرموز الرياضية ($\pi, \sqrt{}, \sin, \cos, \dots$) بسهولة تامة.

5. **التوافقية العالية وتجربة الاستخدام:**
   - متوافق مع كافة أجهزة أندرويد بدءاً من Android 7.0 (API 24) وحتى أحدث الإصدارات، ومحسّن خصيصاً لهواتف مثل **Redmi 10A**.
   - دعم كامل للغة العربية والاتجاهات من اليمين إلى اليسار (RTL).
   - خطوط واضحة وتصميم مريح للعين أثناء الاستخدام المطوّل.

## البنية البرمجية والتقنيات المستخدمة

- **لغة البرمجة:** Kotlin
- **إطار واجهة المستخدم:** Jetpack Compose (Material 3)
- **محرك التعبيرات الرياضية:** mXparser (v5.2.1)
- **إدارة التنقل:** Navigation Compose
- **الرسوميات والأنيميشن:** Compose Canvas & Vector Graphics
- **الأجهزة المستهدفة:** `minSdk = 24`، `targetSdk = 36`

## البناء الآلي وتوليد الـ APK (CI/CD)

يحتوي المشروع على تدفق عمل آلي عبر **GitHub Actions** (`.github/workflows/android_build.yml`) يقوم عند كل رفع للكود (Push) بالخطوات التالية:
1. إعداد بيئة Java 17 وتثبيت نظام أندرويد.
2. بناء حزمة التطبيق بصيغة APK (`assembleDebug`).
3. رفع ملف الـ APK النهائي كأثر (Artifact) جاهز للتحميل والتثبيت المباشر على الهاتف.
